# TDTU CS Student Guide 🎓

A comprehensive resource hub built by students, for students at** ** **Ton Duc Thang University** . This repository is designed to help you navigate the CS curriculum, ace your exams, and automate the boring stuff.

## 📂 Repository Structure

* **`guides/`** : Specialized handbooks (e.g., NCKH/Scientific Research Guide).
* **`past-exams/`** : Archive of past papers for subjects like DSA, Discrete Math, and Software Engineering.
* **`report-templates/`** : Standardized** **`.docx` and** **`.dotx` templates in EN/VN for your lab reports and assignments.
* **`slides-and-books/`** : Essential reading materials and lecture slides.
* **`tricks-and-tools/`** : Scripts and automation tools (like the TDTU Auto Rating script).

* `Template_EN.docx` (For International Program/English-taught courses)
* `Template_VN.dotx` (Standard Vietnamese format)
